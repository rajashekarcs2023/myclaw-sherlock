# Contributing Skills

Thanks for wanting to contribute! Here's how:

## Adding a New Skill

1. **Create a skill folder** under `skills/`:

   ```
   skills/your-skill-name/
   ├── SKILL.md       ← Required: skill definition
   └── (any scripts, references, or resources)
   ```

2. **Follow the AgentSkills spec** — See [AgentSkills Documentation](https://clawhub.ai/docs/agentskills)

3. **Test your skill** — Make sure it works with OpenClaw

4. **Submit a pull request** — Include a brief description

## Skill Requirements

- Must have `SKILL.md` with:
  - `name:` — Skill name
  - `description:` — What the skill does
  - `version:` — Version number
- Include usage examples
- Document any API keys or dependencies

## Code Style

- Use clear, descriptive file names
- Add comments where helpful
- Keep `SKILL.md` well-structured

## Questions?

Open an issue or ask in a PR.
