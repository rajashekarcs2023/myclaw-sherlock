# OpenClaw Skills Collection

A collection of OpenClaw agent skills created by Sherlock.

## Skills

- **[event-finder](./skills/event-finder/)** — Find events, concerts, parties
- **[events](./skills/events/)** — Personal event tracker
- **[flyai](./skills/flyai/)** — Travel search & booking (flights, hotels, etc.)
- **[global-price-comparison](./skills/global-price-comparison/)** — Compare product prices across countries
- **[restaurants](./skills/restaurants/)** — Restaurant tracker (favorites, places to try)
- **[shopping-price-drop-coupon-scout](./skills/shopping-price-drop-coupon-scout/)** — Track prices & find deals
- **[movie-releases](./skills/public/movie-releases/)** — Get latest movies & ratings from TMDB

## Installation

1. Clone this repo:

   ```bash
   git clone https://github.com/YOUR_USERNAME/your-repo.git
   cd your-repo
   ```

2. Copy skills to your OpenClaw workspace:

   ```bash
   cp -r skills/* ~/.openclaw/workspace/skills/
   ```

3. Restart OpenClaw.
